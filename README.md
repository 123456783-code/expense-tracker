# 💰 Expense Tracker

A responsive and user-friendly Expense Tracker web application built using **HTML, CSS, and JavaScript**. It helps users manage expenses, track spending by category, and visualize spending patterns through analytics.

## 🚀 Live Demo

[View Live Demo](https://123456783-code.github.io/expense-tracker/)

## 📂 GitHub Repository

[View Source Code](https://github.com/123456783-code/expense-tracker)

---

## ✨ Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 🔍 Search expenses
- 🏷️ Filter expenses by category
- 💰 Calculate total expenses
- 📊 Display total number of transactions
- 📈 Calculate average expense
- 🔝 Track highest expense
- 📋 Display transaction history
- 📊 Category-wise spending analytics
- 🍩 Interactive doughnut chart using Chart.js
- 💾 Store expenses using LocalStorage
- 🔄 Data remains available after page refresh
- 📱 Responsive design

## 💾 LocalStorage

The application uses the browser's **LocalStorage API** to store expense data, allowing data to remain available after refreshing the webpage in the same browser.


### 2. Open the project

```bash
cd expense-tracker
```

### 3. Run the application

Open `index.html` in your web browser, or use the **Live Server** extension in Visual Studio Code.
